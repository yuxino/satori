`Satori` は日本語の「悟り」——理解し、物事の本質を見通す瞬間——に由来します。

PDF 教材を理解するための、ローカルファーストな macOS アプリです。ローカルの PDF を開き、ページを見ながら、分からないときだけ現在のページや範囲について質問できます。

## 機能

- **ページを見ながら質問する**：現在のページについて尋ねるか、段落・図・コードの上をドラッグして、画像に基づく説明を求められます。テキスト、スキャン、混在 PDF に対応します。
- **読書を優先**：単ページ・見開き表示、目次移動、ズームはページを中心に動作し、本を開くと前回の位置に戻ります。
- **本ごとの文脈を保つ**：読書活動と本ごとの質問・回答をまとめ、保存した回答から元のページを開き直せます。
- **自分の画像対応 AI を使う**：Model Studio、OpenAI、またはカスタムの OpenAI 互換接続を複数保存し、使用するモデルを明示的に選べます。
- **ローカル保存**：元の PDF はそのまま残り、本棚データ、読書状態、過去の質問・回答は Mac に保存されます。API Key は macOS Keychain にのみ保存されます。

## ダウンロード

macOS 14+ と Apple シリコン搭載 Mac が必要です。[GitHub Releases](https://github.com/yuxino/satori/releases/latest) から ZIP をダウンロードし、展開した Satori を「アプリケーション」に移動してください。

現在のソースを実行するには、Node.js 22.13+、Rust、および安定した macOS コード署名 ID（Apple Development または長期利用する自己署名 ID）を用意してください。

```bash
npm install
npm run app
```

ダウンロード版にはローカルのコード署名がありますが、Apple Team ID はなく、Apple の公証も受けていません。初回起動時は、Control キーを押しながら Satori をクリックし、「開く」を選んでもう一度確認してください。更新は公式 Releases ページから手動でダウンロードし、置き換える必要があります。

アプリの表示言語は現在、簡体字中国語のみです。AI を設定しなくても読書できます。質問やスキャン PDF にない目次の認識には、設定で OpenAI 互換 Chat Completions の画像入力に対応するモデルを追加してください。

## プライバシー

PDF は元のローカル保存場所に残ります。本棚のメタデータ、読書状態、本ごとの質問・回答は Application Support に保存され、API Key は macOS Keychain にのみ保存されます。質問の送信、ページや選択範囲の説明、またはページ範囲と画像枚数の表示後に目次認識を確定したときだけ、関連するページ画像が使用中の AI サービスへ送られます。追加の質問には、直近最大 6 ターン分のテキストだけの履歴が含まれる場合があります。本や質問パネルを開くだけでは、ページ内容は AI サービスへ送られません。起動後、Satori は現在のバージョンを使って GitHub Releases を 1 回確認します。このリクエストに PDF の内容、読書履歴、AI 設定、API Key は含まれません。
