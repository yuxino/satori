# satori

A local-first macOS learning workspace for understanding PDFs, related material, and code.

Satori organizes learning around a goal or topic. A project may have a primary textbook, its learning directory, related PDFs and web sources, code references, and AI-assisted explanations. It remembers reading position and learning context locally.

## First learning plan

The initial plan is **Computer Self-Study**, with three course workspaces:

- Advanced Programming
- Software Engineering
- Operating Systems

## Product principles

- Understanding before note-taking
- Local files and local reading history by default
- Clear separation between PDF evidence, web sources, and AI inference
- AI helps explain and connect material; it does not host or own the library
