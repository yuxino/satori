# Satori 本地学习会话设计

## 产品方向

学习助手不再展示一张不断被替换的“答案卡”，而是成为当前 PDF 的学习记录。每轮由问题、对应页码、AI 回答、来源和操作组成；切换教材时切换到那本书自己的记录，重开应用后仍能继续。界面保持 PDF 为主、助手为辅，不扩展成脱离教材的通用聊天工具。空状态只提供三种高价值起点；开始提问后，空状态让位于紧凑的时间顺序记录。每轮可复制回答、重试、删除，并可点击页码回到当时的原文。顶部提供清空本书记录，但需要确认。

## 阅读与排版

模型返回 Markdown，必须按文档而非原始字符串显示。解析层把内容拆成标题、段落、无序/有序列表、引用、代码块和分隔线；行内粗体、斜体、链接和代码继续使用系统 Markdown 属性。代码块使用等宽字体、横向滚动、独立背景和复制按钮。像 `**原文依据**` 这类模型常用的整行粗体会提升为小标题，从根源上消除截图中的星号、反引号和扁平长文本。正文使用更克制的字号、行距和段落间距，来源与操作放入尾部工具栏，不再与正文争夺注意力。

## 数据与 AI 上下文

学习记录单独保存在 Application Support 下的 `learning-sessions.json`，按 PDF 的稳定文档 ID 分组，不写回 PDF，也不进入 Git。用户附图继续只用于当次请求，不保存图片本身，记录只保留“附加了几张”。为支持“这里为什么”“再举个例子”等追问，每次请求最多附带当前书最近六轮的文字问答；当前 PDF 页仍是本轮的首要证据。百炼请求继续使用 `store: false`，因此长期记忆由 Satori 本地控制，而不是交给云端会话。失败请求不写入历史；用户停止后，若已有部分答案，则标记为“已停止”并保留。

## 失败、隐私与验证

历史文件使用原子写入，损坏或缺失时不阻止 PDF 阅读；单轮删除和整书清空均只影响本地会话。网络失败显示在当前草稿中并允许重试。测试覆盖 Markdown 块解析、旧/空会话加载、按文档隔离、覆盖与清空，以及请求中只携带限定数量的历史轮次。真实界面检查覆盖空状态、多轮记录、Markdown 列表与代码、流式草稿、页码跳转、复制/重试菜单和窄面板换行。
