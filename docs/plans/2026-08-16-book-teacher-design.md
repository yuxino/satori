# Satori 3.0 设计：一本书，旁边坐着一个老师

日期：2026-08-16 · 状态：已定稿（用户委托主线程决策）· 目标形态：Tauri 2 重写

---

## 1. 结论先行

- **推倒 SwiftUI 界面**，用 Tauri 2 + PDF.js 重写。
- **核心范式：页面即证据**——视觉模型直接读页面图像，**不建 OCR 管线**。
- **产品形态：全屏书页 + 被召唤才出现的老师。**
- 唯一验收标准：**用户真的能用它读懂一本难书。**

## 2. 为什么推倒（诊断复盘）

1. 旧 App 是「工作台」：90 条功能记录，侧栏、阅读栏、面板、胶囊抢眼睛，书页只是其中一个格子。用户原话：「整体不对味」。
2. **核心循环从未被验证**：status.md 里全是「回路跑通」的验证，没有一条是「我用它学懂了一章，感觉很好」。
3. SwiftUI 迭代慢，排版和手感磨不出来，于是靠堆功能补偿。
4. OCR 管线是巨大的复杂度源（分类、文字层修复、验真、页码映射……），而 VLM 直接读图让整条管线**从第一天就不存在**。

## 3. 产品定义

> **打开 = 书摊开；卡住 = 问一句；讲完 = 回到书。**

- 不是聊天工具、不是笔记工具、不是做题工具、不是工作台。
- 读者画像：底子一般，想读懂教材，不是做题家。所以默认要「讲得懂」，不是「讲得全」。

## 4. 阅读面（书桌）

- 全屏书页，**零常驻 UI**。
- 悬停显示一条极简阅读栏（页码 + 当前章节），约 2 秒后自动淡出。
- 目录像书签一样**从左侧边缘滑入**（⌘T 或边缘悬停），看完滑走。
- 打开书自动回到上次阅读位置。
- 排版原则：书页是主角，界面退后；阅读区衬线、宽松行距（具体视觉定稿后统一 token）。

## 5. 问老师（核心交互）

- **划选文字** → 选中处出现安静的「不懂这段」胶囊。
- **没划选** → 页边是安静的书页形「问书」入口。点击只展开提问面板，不读取 Keychain、不调用模型；发送问题或明确选择「讲讲这一页」后才发起请求。
- **回答出现方式**：底部滑出一个安静的面板（约窗口下 1/3），**不遮住整页**，选中段落保持高亮。
- 面板内容：问题复述（小字）→ 回答（短）→ 三个按钮：**再讲细一点 / 举个例子 / 换个说法**。
- 可自由追问，对话绑定当前页；翻页后面板收起，问答自动归档。
- Esc 或点击空白处收起。

## 6. 老师的讲法（提示词约束）

- 默认回答 **3–6 句**：一句主线 → 大白话解释 → 对上术语（书上叫 X，就是我们刚说的 Y）→ 一句「所以」。
- 用户说「还是不懂」→ **换角度，不加篇幅**。
- 必须引用页面图像；看不清就明说「这页图我看不清」，**绝不猜测**。
- 不堆术语、不评判、不灌鸡汤、不写小作文。

## 7. 记忆与回看

- 阅读位置静默保存（不可见、自动）。
- 每页 Q&A 静默归档（不可见、自动）。
- 重开书时一行轻提示：「上次读到第 N 页」。
- 回看入口：⌘R 或目录抽屉 → 按页列出问过的问题 → 点击跳回该页、恢复选中、显示原回答。
- **无徽章、无连击、无进度百分比。**

## 8. 技术骨架（选型放最后，服从产品循环）

- **Tauri 2 + Rust 壳**；前端 TS + Vite + PDF.js，不引重型框架，依赖越少越好。
- 提问时：当前页渲染成图（选中区域可裁切）→ JPEG → 送视觉模型。
- **模型后端抽象**：云端起步（百炼 `qwen-vl-ocr` / Qwen3-VL，有免费额度），本地 MLX Qwen3-VL 作为可选离线后端，切换不碰 UI。
- **API Key 迁移**：Rust `keyring` 读旧条目（service `com.yuxino.satori.qwen.v2`，account `qwen-api-key`）；读不到则在设置页重新粘贴，Key 只进 Keychain。
- 存储：Application Support 本地 JSON（书库、阅读位置、每书 Q&A）。
- **明确不做（本期）**：web 搜索、代码运行、验证一下、实验、OCR 目录恢复、印刷页码映射、复习调度。
- 旧 Swift 代码打 tag 保留，工作区换新结构。

## 9. MVP 验收（就这一条循环）

导入扫描版《操作系统》→ 翻到不懂的一页 → 划一句 → 得到 3–6 句能看懂的解释 → 点「举个例子」能接上 → 关掉重开还在那页 → 回看能找到昨天的问答。

**别的都不算完成。**

## 10. 实施顺序（下一步）

1. Tauri 骨架：窗口 + PDF.js 渲染 + 翻页 + 位置保存。
2. 提问闭环：页图 → 百炼 VLM → 底部面板回答。
3. 老师讲法：提示词 + 三个按钮 + 追问。
4. 记忆与回看：归档 + 重开提示。
5. 用真实教材完整读一章，按 MVP 验收标准检验。
