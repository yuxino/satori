# Satori 整体 UI / UX 重设计

## 目标

把 Satori 从“统计面板 + PDF 工具条 + AI 浮窗”统一成一个安静的私人学习书房。界面首先帮助用户接着读、看清书页、在卡住时得到解释；活动数据和模型能力退到背景。

## 方向选择

我们比较了三种方向：

1. 延续数据总览，只提升卡片和图表质感。改动小，但仍会把学习误导成打卡。
2. 做传统电子书架。书的管理更清楚，但进入学习的理由和上下文不足。
3. 做“今日书桌”。用当前书和上次位置建立主线，书架、学习节奏和问过的问题作为辅助。

采用第三种。它更贴合 Satori“为了理解而读，不为了考试或记笔记”的定位。

## 体验架构

### 主页：今日书桌

- 顶部只保留品牌、简短定位和全局操作。
- 首屏主角是最近阅读：由书名稳定生成的排版封面、书名、页码、进度和一个明确的“继续阅读”。排版封面不依赖低清缩略图，也不生成与内容无关的 AI 插画。
- 同一区域用一句自然语言呈现今天或最近的学习节奏，不再用四张统计卡片抢注意力。
- 书架改为纵向书脊式列表，书名、进度、问过次数和继续入口在一行内完成判断。
- 最近问答改名为“最近弄懂的”，显示问题及回答摘要，让它成为可回到的理解痕迹，而不是聊天记录。
- 保留完整的 52 周学习活动格子，这是用户明确喜欢的反馈方式；不附带排名、目标或四张统计卡，避免把它变成考核。

### 阅读器：书页优先

- 底部整宽状态栏改为居中的浮动阅读轨，按“回到书房 / 书与目录 / 翻页与位置 / 视图”分组。
- 章节名称作为低权重上下文，不与页码争夺注意力。
- 缩略图保持按需展开，但视觉上属于阅读轨，不再像第二层工具栏。
- 问书入口保留书页图标，缩小阴影和装饰，让它像页边书签。

### 问书：学习对话

- 面板标题明确为“问书”，同时显示当前页上下文。
- 用户问题呈现为小型提问引文；回答采用适合屏幕阅读的无衬线排版，不使用聊天气泡或 AI 头像。
- 快捷追问由胶囊按钮改为安静的文本动作，减少“按钮墙”。
- 初始态提供三个具体启发问题，仍然只有用户点击或发送后才读取 Keychain 和调用服务。
- 输入区固定在底部，问题输入和发送具有清楚的启用状态；历史视图使用时间线式列表。

## 视觉系统

- 概念：冷中性编辑工作台 / 纯白内容面 / 石墨文字 / 深蓝灰作为书签色，明确避开常见 AI 产品的米灰与淡紫组合。
- 字体：标题与书名使用宋体，功能和回答使用苹方；不引入网络字体。
- 颜色：冷灰画布、纯白表面、深石墨正文、低饱和蓝灰强调；深色模式保持相同层级关系。
- 形状：控件圆角 8px、内容卡 14px、浮层 16px；胶囊只用于真正的状态或小型标签。
- 动效：主页内容轻微分段进入、悬停只做 1–2px 位移；减少动态模式关闭所有非必要动画。

## 状态与可访问性

- 空书架时主页首屏直接解释价值并提供“打开 PDF”，不展示空统计。
- 所有书默认使用本地生成的排版封面，颜色由书 ID 稳定映射，任何尺寸都保持锐利。
- 首页、书架、最近理解、阅读轨和问书动作全部使用原生 button 语义和 `focus-visible`。
- 主页在窄窗口转为单列；问书面板在低窗口中限制高度并保持输入区可见。
- 不改变本地优先、凭据读取时机或 AI 请求安全边界。

## 验收

- 启动后 3 秒内能明确看到正在读什么以及如何继续。
- 首页不再出现统计卡片矩阵，但保留完整年度学习格子。
- 主页、阅读器和问书面板看起来属于同一套产品。
- 打开问书面板不会读取 Keychain；只有主动提问或测试连接才可能触发授权。
- 720×520、默认窗口、深浅色和键盘操作下均无关键内容裁切。
