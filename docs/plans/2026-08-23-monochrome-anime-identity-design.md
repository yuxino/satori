# Satori 黑白二次元视觉身份设计

## 目标

让 Satori 具有明确的个人气质：界面以黑、白、灰为绝对主色，保持简洁和长期阅读的安静感；二次元风格集中在角色图标与极少量细节，不把整个应用做成粉紫色动漫主题。

## 图标

- 保留现有 Satori 角色身份：银白短发、呆毛、侧编发、书本发夹、金色眼睛与手中的书。
- 采用 Kiri 图标的 Q 版比例、圆形徽章构图和清晰线条，但不复制 Kiri 的角色、发饰、字母、蝴蝶结、花朵或紫粉配色。
- 黑白灰占图像九成以上，只在眼睛、书本发夹和书签保留少量暖金。
- 不放 `satori`、汉字或任何字母，保证 Dock 小尺寸仍能识别人物和书。

## 界面

- 浅色：暖度极低的纸白画布、纯白内容面、近黑正文、灰色辅助文字。
- 深色：近黑画布、深灰内容面、柔白正文，不反转成高亮霓虹主题。
- 所有主要操作使用黑 / 白对比；暖金只出现在当前日期、焦点或极少量身份细节。
- 年度学习格子改为完整灰阶；文字书封改为六档石墨灰，不再使用蓝、紫、绿、棕色板。
- 卡片减少阴影，主要依靠 1px 线条、留白和排版建立层级。
- 设置页继续使用服务文字标签，强调色与主应用一致，不再保留蓝紫色 token。

## 代码整理

- 把历史遗留的 `--lavender` / `--lavender-soft` 重命名为语义化的 `--accent` / `--accent-soft`。
- 搜索并删除不再有 DOM 或 TypeScript 引用的首页样式、旧图标引用、未使用导出和无效分支。
- 不删除持久化字段、Tauri 命令、迁移兼容或测试使用的代码。

## 验收

- 默认首页第一印象是黑白、简洁，而不是蓝灰、米灰或紫色 AI 产品。
- 新图标在 32、128 和 512 像素均能看出银发角色与打开的书。
- 首页、阅读器、问书和设置属于同一视觉系统；语义状态仍可区分。
- 打开首页、问书初始态和设置不会读取 Keychain。
- TypeScript、Vite、Rust 测试、Clippy、格式检查和 release 打包全部通过。
