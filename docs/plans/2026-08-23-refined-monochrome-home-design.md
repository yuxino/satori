# 首页「黑白编辑台」设计

## 问题

首页曾把“高端点的设计”误读成具体的车票主题，加入深色票夹、裁切角、打孔、虚线、防伪纹、票号和大量票据英文。装饰压过了阅读内容，也让界面像套用的主题模板。

## 方向

首页回到高级、克制的黑白编辑式设计，不借用车票、证件、禅意印章或其他具象主题。

- 画布使用纯净的中性浅灰，内容表面使用白色；不使用米黄纸张、蓝紫雾面或深色外框。
- 视觉重点来自排版、留白、细线、比例和真实内容，而不是纹理、锯齿、打孔或编号。
- 顶部只保留 `satori` 字标、齿轮设置入口和必要的“返回书页”，不放产品口号或装饰性英文。
- 当前阅读仍是首页主区：清晰的文字封面、书名、页数、最近阅读提示、进度与继续按钮。
- “上次提问”是主区右侧的轻量信息，不做独立卡片；学习格子、书架与最近问答保持原有信息结构。界面只陈述发生过的提问和回答，不替用户判断是否已经理解。
- 暖金只保留给书签和当天格子，不用于边框、编号或大面积装饰。

## 交互与适配

- 不改变任何数据、点击目标、学习记录或 Keychain 时机。
- 设置按钮保持原生 button 语义，提供 `aria-label`、tooltip 与清晰焦点。
- 860px 以下当前阅读区重排；680px 以下隐藏低优先级说明；720×520 下仍可滚动使用。
- 浅色与深色模式沿用全局语义色，不强制首页成为独立主题。

## 验收

- 第一眼是安静、清楚、有质感的学习首页，而不是车票模板或统计看板。
- 保留用户喜欢的 52 周格子和锐利文字封面。
- 页面上不存在 `READING PASS`、`ADMIT ONE`、票号、打孔、裁切角、防伪纹和虚线票据分隔。
- 设置入口是齿轮图标，不显示“AI 服务”作为首页导航。
- 首页打开不读取 Keychain，也不调用 AI。
