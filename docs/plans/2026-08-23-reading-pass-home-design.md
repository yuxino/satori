# 首页「阅读凭证」设计

## 问题

当前首页虽然克制，但整体仍像一张排版规整的文档：白色画布、普通标题栏和一个独立白色主卡片，缺少能被记住的产品身份。右上角“AI 服务”实际打开设置，却以普通文字出现，用户很难一眼判断它是设置入口。

## 方向

把整个首页设计成一张放在深色桌面上的收藏级阅读车票（Reading Pass），而不是给单个卡片加票券贴纸。

- 视口使用近黑石墨桌面，票面使用偏冷象牙白；黑、白、灰占绝对主体，暖金只作为烫金编号、书签和当天标记。
- 外层票面使用双线描边、裁切角、细密防伪纹与极轻纸张颗粒，形成材质和层次，但不使用米黄复古、做旧污渍、渐变霓虹或大面积阴影。
- 顶部改成票面抬头：`satori` 字标、`READING PASS / PRIVATE EDITION`、本地优先标识和票号。删除“PDF 学习书房”这类产品说明口号。
- “AI 服务”改为带明确 `aria-label` 和 tooltip 的齿轮设置按钮；存在已打开书时，“返回书页”仍保留为文字动作。
- 当前阅读区成为主票联：顶部有凭证编号，左右留半圆打孔，进度线像验票线；“上次弄懂”是虚线分隔的副券，不再像第三张空卡。
- 学习格子、书架和最近理解继续留在同一票面上，使用票据分区线组织，不增加统计卡或装饰性模块。

## 交互与适配

- 所有原有点击目标、数据与 Keychain 时机不变；本轮只改变首页 DOM 的非业务标记与 CSS。
- 设置齿轮保持原生 button 语义，支持键盘焦点、hover 和 tooltip。
- 860px 以下票面减少外边距，主票联改为两列；680px 以下隐藏次要票面说明与副券。
- 深色系统下仍保持“深色桌面 + 浅色票面”，避免整张票反相后失去纸券识别；正文对比度维持可读。

## 验收

- 第一眼能感受到一整张高级阅读车票，而不是白底网页或普通圆角卡片。
- 顶部不再显示“PDF 学习书房”和“AI 服务”文字；设置入口可被识别为设置。
- 暖金面积克制，只有票号、书签、焦点和当天格子使用。
- 默认窗口同时看到当前书、完整学习格子以及书架/最近理解开头。
- 720×520、键盘、减少动态模式可用；首页打开不读取 Keychain。
