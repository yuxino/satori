# Qwen 助手接入设计

## 目标与取舍

Satori 的 AI 助手从 OpenAI 切换为阿里云百炼 Qwen。此次不加入供应商选择器，Qwen 是唯一入口，避免在仍处于早期阶段的产品中引入两套密钥、模型和错误状态。用户在百炼创建按量付费 API Key 时，同时获得与地域及业务空间对应的 API Host；设置页保存这两项，其中密钥进入 macOS 钥匙串，API Host 作为普通本地偏好保存。应用不提供写死在仓库里的密钥，也不复用聊天产品的登录状态。

## 数据流与能力

学习面板继续提取当前 PDF 页面。文字页作为 `input_text` 发送；扫描页渲染为压缩 JPEG，再以 Base64 `input_image` 发送。两种页面统一调用百炼兼容的 Responses API，默认模型为 `qwen3.7-plus`：官方文档确认其支持文字、图像和内置网页搜索，因此无需为扫描页维护第二套模型。用户打开“联网”后，请求增加 `web_search` 工具；返回文本和 URL 注解继续映射到 Satori 已有的来源卡片。默认请求不串联历史响应，学习记录仍留在本机。

## 错误与验证

API Host 会先去除首尾空白和末尾斜杠，再安全追加 `/responses`；无效地址在设置页直接提示。未配置密钥或地址时，学习面板引导用户进入设置。HTTP 错误优先显示百炼返回的错误消息，响应无法解析或没有正文时显示可理解的中文提示。核心夹具验证请求地址、鉴权、模型、文字/图片内容、可选搜索工具及响应解析；随后运行核心检查、debug/release 构建，并打开打包应用检查设置页和学习面板。
