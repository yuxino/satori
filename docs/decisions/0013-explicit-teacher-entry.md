# 0013：问书入口不触发 AI 请求

日期：2026-08-22  
状态：已采纳

## 决定

- 阅读页的老师入口使用书页图标，不使用通用的 AI 星光、机器人或拟人教师图标。
- 点击入口只打开提问面板并聚焦输入框，不读取 Keychain、不生成书页图片、不访问模型服务。
- 只有用户发送具体问题、明确点击「讲讲这一页」，或完成明确的框选操作，才允许读取凭据并发起问书请求。
- 扫描目录识别是目录抽屉里的独立动作，不属于问书入口；它必须先披露两阶段会发送的具体页码范围与张数，再等待用户点击。

## 原因

入口的含义是“我准备问书”，不是“立即把这一页交给 AI”。把系统授权与网络请求放在明确动作之后，既避免开发环境的意外钥匙串弹窗，也让本地优先和按需发送的隐私边界在交互上可见。
