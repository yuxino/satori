# 0009: Figure-aware PDF evidence

## Context

文字层可靠的 PDF 也可能把关键知识放在图、表或空间关系里。真实的操作系统教材第 187 页就是这种情况：前一页末尾写“磁盘的结构如图 6-2 所示”，下一页顶部才出现磁道、扇区、柱面的图。只发送文字时，模型能读到术语，却看不到读者正在看的结构图。

## Decision

- 对当前页和不超过 4 页的短桥接，检查当前页以及前一页尾部是否出现编号图/表或常见图示标记。
- 命中时，最多附带 2 张对应页面图像，并在请求中标明图像页码；长章节路线和整本书概览继续文字优先。
- 仍保留文字层作为主证据，图像只用于核对箭头、空间关系、数字、公式和表格，不把每个文字页都升级成图片请求。
- 图像页要求模型具备图片能力；不支持图片的模型在请求前给出能力错误，不静默丢图。

## Consequences

短页桥接对教材图示的理解更接近读者实际看到的页面，尤其适合“这一页和前面怎么接”“图里的磁道是什么意思”这类问题。代价是命中图示的请求会增加图片上传和模型视觉处理时间；通过只处理短范围、最多两张图来控制心流和请求体积。
