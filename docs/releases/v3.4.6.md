## English

Satori 3.4.6 fixes reading state during PDF switches, saved-page restoration and zoom, and updates the app icon. Learning data formats, AI provider settings and signed update configuration remain unchanged.

- Pending zoom, resize and spread-layout work from an old book can no longer alter the new book's page or preferences.
- Restored pages are positioned and rendered before opening completes. The reader retains its page map while waiting for page sizes.
- Keyboard, toolbar, pinch and Ctrl+wheel inputs during loading no longer save an unapplied zoom value. Gestures already accepted can finish on their original reader, so a cancelled or failed open leaves the previous book usable.
- The app uses the approved cat-hood character with a transparent circular icon.
- Windows release packaging uses the exact verified source commit.

Requires macOS 14+ on Apple silicon or Windows 11 x64/ARM64. Version 3.4.4 and later can use the signed in-app updater; older versions need a one-time manual installation of the current release. macOS retains its local signature without notarization; Windows installers are not Authenticode-signed. Automated checks and hosted install/uninstall verification do not claim a new end-to-end updater interaction test on physical devices.

## 中文

# Satori 3.4.6

这一版修复切换 PDF、恢复阅读位置和缩放时的状态错误，并更新应用图标。本地学习数据格式、AI 服务配置和签名更新设置保持不变。

- 切换书籍后，旧书尚未完成的缩放、窗口重排和单双页切换不会再改变新书的页码或阅读偏好。
- 恢复到较后页时，先定位并渲染目标页；等待页面尺寸期间保留有效页码，避免临时跳回第一页。
- 打开 PDF 期间，键盘、工具栏、捏合和 Ctrl+滚轮输入不会保存尚未显示的缩放比例。之前已经开始的手势可在原书上完成，打开取消或失败后仍能继续阅读与框选。
- 应用使用已选定的猫耳兜帽角色和透明圆形图标。
- Windows 发布打包固定使用已校验的源码提交，确保各平台产物来自同一版本。

## 下载与更新

- macOS 14+ Apple 芯片：`Satori-v3.4.6-macos-arm64.zip`。
- Windows 11 x64：`Satori_3.4.6_x64-setup.exe`；ARM64：`Satori_3.4.6_arm64-setup.exe`。
- 3.4.4 及更新版本可在设置中使用签名更新；3.4.3 或更早版本需先手动安装当前版本一次。
- macOS 继续使用稳定本地签名和 hardened runtime，未做 Apple 公证；Windows 安装包未做 Authenticode 签名。首次打开可能需要系统允许的手动确认。
- Release 提供三平台 updater 签名、SHA-256 清单和 `latest.json`。自动化检查与 Windows 托管安装/卸载验证不等同于真实设备上的完整更新交互验收；本版未新增此项验收。
