## English

Satori 3.4.7 makes Windows installation clearer and streamlines in-app updates.

- Windows setup now has Satori's own high-resolution character artwork, a cleaner layout, and English, Simplified Chinese, and Japanese text. Its optional GitHub link opens only when clicked.
- After downloading and verifying an update in Settings, **Install and reopen** shows Windows update progress and reopens Satori when finished. There is no need to find the package on Releases or uninstall the old version yourself.
- Reading position is saved before installation. macOS continues to offer an explicit **Restart and finish** action after installation.

Version 3.4.4 and later can update from Settings. Version 3.4.3 and earlier need
one manual installation of the current release. Downloads cover macOS 14+
Apple silicon and Windows 11 x64/ARM64.

Updates carry signatures verified against Satori's existing public key. The
macOS app retains its stable local signing identity without Apple notarization;
Windows installers remain unsigned by Authenticode. Use the normal system Open
flow when needed. Automated checks and hosted installer verification do not
replace a complete cross-version update test on a user's device.

## 中文

Satori 3.4.7 改善 Windows 安装界面，并让应用内更新更顺畅。

- Windows 安装程序采用 Satori 专属高清人物、更清楚的排版，以及英文、简体中文和日文文案。GitHub 链接只在主动点击时打开。
- 在设置中下载并验证更新后，点击“安装并重新打开”，即可看到 Windows 更新进度，完成后自动重新打开 Satori。无需再去 Releases 找安装包，也不用自己卸载旧版本。
- 安装前先保存阅读位置。macOS 继续在安装完成后提供“重启并完成”按钮，由用户决定重启时机。

3.4.4 及以后版本可在设置中更新；3.4.3 及更早版本需要先手动安装当前版本一次。提供 macOS 14+ Apple 芯片和 Windows 11 x64、ARM64 下载。

更新包使用 Satori 现有公钥验证签名。macOS 继续使用稳定本地签名，未做 Apple 公证；Windows 安装包未做 Authenticode 签名。如系统提示，请使用正常的手动打开流程。自动化检查和托管安装验证不能代替用户设备上的完整跨版本更新验收。
