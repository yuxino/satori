# Satori 3.4.4

这一版建立经过签名的应用内更新链路。设置页会显示新版本和版本说明；用户明确点击后，Satori 使用官方 Tauri updater 下载并验证签名，验证成功后才提供安装入口。下载有总量时显示真实进度，没有总量时使用不定进度，不会伪造百分比，也不会后台下载或静默安装。

## 首次迁移

- **3.4.3 或更早版本必须手动安装 3.4.4 一次。**旧版本没有 updater 公钥和清单能力，无法在应用内完成这次升级。
- 安装 3.4.4 后，后续签名版本可以在设置中检查、下载、验证和安装。
- macOS 安装完成后由用户点击“重启并完成”。Windows 点击“安装并退出”后，Satori 会按系统安装器限制退出，并把控制交给可见的 Windows 安装器。
- GitHub Releases 页面只在 updater 失败时作为恢复入口。

## 下载与验证边界

- macOS：Apple 芯片、macOS 14+；下载 `Satori-v3.4.4-macos-arm64.zip`。包继续使用项目稳定的本地签名身份和 hardened runtime，但没有 Apple Team ID，也未经过 Apple 公证。
- Windows：Windows 11 x64 下载 `Satori_3.4.4_x64-setup.exe`，ARM64 下载 `Satori_3.4.4_arm64-setup.exe`。安装包按当前用户安装且未经过 Authenticode 签名，因此会显示未知发布者提示。
- Release 同时提供三个 updater 签名、`latest.json` 和分平台 SHA-256 清单。updater 签名不替代 Apple 公证或 Authenticode。
- Windows 两个架构都必须通过托管构建、测试、唯一 payload、PE 架构、产品身份、安装和完整卸载验证；这些证据不等同于真实设备上的完整更新交互验收。

---

Satori 3.4.4 introduces signed in-app updates. Settings shows the version and release notes first; an explicit download uses the official Tauri updater and exposes installation only after framework signature verification. Known download totals use real byte progress, unknown totals remain indeterminate, and Satori never downloads or installs an update in the background.

**Bootstrap:** installations on 3.4.3 or earlier must manually install 3.4.4 once from GitHub Releases. Later signed versions can then be checked, downloaded, verified, and installed in-app. macOS waits for an explicit **Restart and finish** action. Windows exits after the user starts installation and hands control to the visible installer. GitHub Releases remains error recovery only.

---

Satori 3.4.4 では、署名付きのアプリ内更新に対応します。設定にはバージョンとリリースノートが先に表示され、明示的にダウンロードすると公式 Tauri updater が署名を検証します。検証が完了するまでインストール操作は表示されません。既知の総量には実際の進捗を使い、不明な総量は不定表示のままにします。バックグラウンドダウンロードや無断インストールは行いません。

**ブートストラップ:** 3.4.3 以前を使用している場合は、今回だけ GitHub Releases から 3.4.4 を手動でインストールする必要があります。その後の署名付きバージョンはアプリ内で確認、ダウンロード、検証、インストールできます。macOS は「再起動して完了」を明示的に選ぶまで待機します。Windows はインストール開始後に終了し、表示されたインストーラーへ処理を引き継ぎます。GitHub Releases はエラー時の復旧手段としてのみ表示されます。
