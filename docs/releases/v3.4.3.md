# Satori 3.4.3

这一版是跨平台打包维护更新。它复核了 Windows 兼容层、依赖、资源和回归测试，在不删除功能、诊断与安全能力的前提下缩小正式程序。

## 主要变化

- 逐项复核单实例与数据锁、LocalAppData、Credential Manager、原子覆盖写入、平台更新匹配和完整卸载验证；没有发现需要删除或替换的跨平台逻辑。
- 保留全部 47 个前端测试和 47 个 Rust 测试；没有以减小包体为由删除仍有价值的回归测试、PDF 解码资源、源映射或安全检查。
- 正式 Rust 构建改用单个 codegen unit。相同源码与前端输入下，macOS arm64 原生程序从 9,401,920 bytes 降至 8,708,976 bytes，减少 692,944 bytes（7.37%）。

## 下载与验收边界

- macOS：需要 Apple 芯片 Mac 和 macOS 14+。下载 `Satori-v3.4.3-macos-arm64.zip`，解压后把 Satori 移入“应用程序”。包使用项目稳定的本地签名身份和 hardened runtime，但没有 Apple Team ID，也未经过 Apple 公证。
- Windows：需要 Windows 11。x64 下载 `Satori_3.4.3_x64-setup.exe`，ARM64 下载 `Satori_3.4.3_arm64-setup.exe`。安装包未经过 Authenticode 签名，并按当前用户安装，因此 Windows 会显示未知发布者提示。
- 两个 Windows 安装包只从同一最终源码提交的成功托管产物提升；构建、测试、唯一 payload、PE 架构、产品身份、当前用户安装、完整卸载和 SHA-256 都必须在上传前通过。
- 原生交互证据按正式产物和架构分别记录。本版不把 macOS 验收、托管 Windows CI 或旧 ARM64 原生证据描述成 3.4.3 Windows 原生验收，也不推断 x64-on-x64 手动验收。
- Release 附带校验清单，用于核对三个平台资产。

---

Satori 3.4.3 is a cross-platform packaging maintenance release. It audits the Windows compatibility layer, dependencies, resources, and regression tests, then reduces the release executable without removing product behavior, diagnostics, security checks, PDF decoder assets, source maps, or useful tests.

The same-source macOS arm64 release executable decreased from 9,401,920 to 8,708,976 bytes by using one Rust codegen unit. The Release includes a locally signed, hardened-runtime macOS 14+ Apple silicon build that is not Apple-notarized, plus unsigned current-user NSIS installers for Windows 11 x64 and ARM64. Windows assets are promoted only from a successful hosted run at the exact final source commit. Native evidence remains artifact- and architecture-specific.
