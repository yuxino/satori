`Satori` 来自日语「悟り」——理解、看清事物本质的瞬间。

一个 macOS 应用，用来读 PDF 教材。打开书就是全屏阅读；遇到看不懂的段落、图或代码，选中它，就会得到针对这一部分的解释。

## 功能

- **问页面上的任何内容**：选中一段话、一张图或一段代码；文字版和扫描版都能用。
- **是阅读器，不是工作台**：连续滚动、捏合缩放、页面缩略图、按页码直接跳转。
- **你的书和历史**：随时切换书；阅读位置和过往问答都保存在本机。

## 开始使用

需要 macOS 14+。

```bash
npm install
npm run app
```

## 隐私

书和阅读历史都存在本机。解释由你配置的 AI 服务根据相关书页图像按需生成。
