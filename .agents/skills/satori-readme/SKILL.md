# satori 双语 README 维护

## 文件结构

- `README.md` — 英文（GitHub 默认展示页）
- `README_ZH.md` — 简体中文

两个文件互相链接（头部 `<p>` 里的语言切换），**必须同步维护**。

## 硬规则（违反即返工）

1. **每语只写自己的语言**——英文文件使用英文，中文文件使用中文。README 不包含日文正文、日文原词引用或日文版导航，也不生成日文 README。
2. **名字由来使用当前文档语言说明**：
   - EN：`Satori means “enlightenment” in Japanese.`
   - ZH：`Satori 在日语中指理解、看清事物本质的瞬间。`
3. **内容完全对齐**：中英文段落一一对应（标题、副标题、正文每段、列表项、命令块、页脚）。改一处必须同步另一版。
4. **语气统一**：产品介绍要朴素、大白话、不夸张。禁止"老师""AI 给你讲"这类宣传腔；用平静陈述句。
5. **保持头部排版**：居中 `<div align="center">` + logo + `<h1>` + 副标题 + 语言切换链接，不要改动结构。

## 工作流

1. **先定中文版**（产品意图的源头），再译 EN。
2. 改任何一版后，**逐段对照另一版**，确认段落一一对应。
3. 自查：检查两份文件的语言导航与内容对齐，并确认没有日文正文或日文版链接。
4. 提交信息标注 `docs:`，一次提交双语。

## 反例（不要做）

- 只在 `README.md` 加内容、不动 `README_ZH.md` → 双语失同步。
- 英文文件里直接贴中文句子或日文汉字作正文。
- 加"开始使用/文档链接/开发细节"等非产品内容（README 是产品介绍，不是开发文档）。
